# 01 設備連線資訊

難度：基礎

## 題目說明

監測站啟動後，需要顯示本次連線的設備名稱與通道編號。讀取兩項資料，依指定格式產生連線資訊。

## 輸入格式

第一行是一個不含空白的設備名稱，第二行是一個整數通道編號。

## 輸出格式

輸出兩行，格式依序為 Device: 名稱 與 Channel: 編號。冒號後各有一個半形空格。

## 資料範圍

名稱由英文字母、數字及底線組成，長度 1～20；通道編號 0～99。

## 範例

### 輸入

```text
sensor_A
7
```

### 輸出

```text
Device: sensor_A
Channel: 7
```

## 範例說明

sensor_A 是設備名稱，7 是它使用的通道。
